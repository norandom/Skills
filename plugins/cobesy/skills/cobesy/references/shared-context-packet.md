# Shared context packet

Use this packet when adoption work consumes or hands off negotiation,
investigation, intelligence-analysis, or foresight results. Keep the existing
names and identifiers; do not rebuild the same evidence under new labels.

| Field | What to carry |
| --- | --- |
| Actors | Parties, agents, approvers, hidden principals; add network roles such as anchor, bridge, or seed cluster. |
| Claims | What each party says is true. |
| Evidence | Supporting or contradicting observations, sources, confidence, and gaps. |
| Assumptions | Beliefs driving the choice, including cultural assumptions. |
| Scenarios | External futures that change the plan or its payoffs. |
| Options | Offers, concessions, outside options, and adoption alternatives. |
| Payoffs | Money, risk, time, reputation, and control. |
| Constraints | Deadlines, authority, law, policy, technical limits, and cultural limits on what is safe to say. |
| Open questions | Unknowns that change the next move, including disproof conditions. |

Use stable IDs such as `A1 buyer`, `C3 demand forecast`, `S2 recession case`,
and `O4 staged rollout`. Preserve those IDs in briefs and diagrams so outputs
can be compared without translating names.

This is the shared packet used by this repository's game-theory-negotiation
skill, included here for independent COBESY installation. The workflow does
not require that other skill to be installed.
