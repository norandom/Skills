# Facilitation Games (Gamestorming)

**Source:** Gray, Brown & Macanufo, *Gamestorming*.

When COBESY needs a **live session** (workshop, kickoff, alignment), use these
structured games instead of open discussion or icebreakers. A game is a temporary
**alternative world** with explicit boundaries, rules, artifacts, and a goal.

---

## The shape of every session

Picture a pencil sharpened at both ends: **open wide, explore, close tight.**

```
 OPENING            EXPLORING              CLOSING
 (divergent)        (emergent)             (convergent)
   ╲                  ▭▭▭▭▭                  ╱
    ╲  blue-sky,     patterns,             decide,  ╱
     ╲ many ideas    connections           commit  ╱
```

**Three acts:**
1. **Opening** — divergent. Generate, open up, suspend judgment.
2. **Exploring** — emergent. Find patterns, test, connect.
3. **Closing** — convergent. Decide, prioritize, assign.

**Two hard rules:**
- Never **open and close at the same time** (no judging while generating).
- **Close everything you open** — every divergence must converge to a decision or
  it was wasted.

---

## Game library mapped to COBESY phases

### To DIAGNOSE the system (Phase 1 — Systemic)
- **The Anti-Problem** — "How could we make this *fail* completely?" Surfaces
  hidden assumptions and survival rules safely (it's a game, so it's safe to be
  honest). Pairs with Schein diagnosis.
- **The 5 Whys** — drill from a symptom to a root underlying assumption.

### To GENERATE (Phase 2 — Cognitive / content)
- **3-12-3 Brainstorm** — 3 min observations → 12 min concepts → 3 min pitches.
  Time-boxed divergence that fits working-memory limits.
- **Brainwriting** — silent written idea generation before discussion; defuses
  reactance and status effects, so quieter experts contribute (Knowles).

### To BUILD CONSENSUS (Phase 3 — Behavioral)
- **Affinity Map** — cluster ideas to reveal shared structure; creates the
  visible social agreement that complex contagion needs.

### To DECIDE / close (Phase 4 — Assemble)
- **Dot Voting** — fast convergent prioritization; makes group preference visible
  (social proof).
- **Forced Ranking** — strict ordering against criteria when dots aren't decisive.
- **Who/What/When Matrix** — the accountability close: every decision gets an
  owner, an action, and a date. Never end a session without this.

---

## Sequencing rule for cascades

Order speakers and contributions to start a **positive cascade** (Easley &
Kleinberg): put respected, objective voices first; use silent/written formats
(Brainwriting) early to prevent a premature negative cascade from one loud
skeptic.

## Mapping table

| COBESY phase | Goal | Game(s) |
|---|---|---|
| Systemic (1) | Surface hidden rules | Anti-Problem, 5 Whys |
| Cognitive (2) | Generate / compress | 3-12-3, Brainwriting |
| Behavioral (3) | Visible consensus | Affinity Map |
| Assemble (4) | Decide + own | Dot Voting, Forced Ranking, Who/What/When Matrix |
