# Agenda Pyramid (Minto)

A top-down agenda skeleton. Lead with the conclusion; never list topics
chronologically.

## SCQA opener (say this first, ~60 seconds)
- **Situation** (agreed context): _____
- **Complication** (what changed): _____
- **Question** (raised by the complication): _____
- **Answer** (your conclusion — the top of the pyramid): _____

## The pyramid

```
                 ┌─────────────────────────────┐
                 │  GOVERNING CONCLUSION         │   ← lead with this
                 └──────────────┬──────────────┘
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
   ┌────────────┐        ┌────────────┐        ┌────────────┐
   │ Key point 1│        │ Key point 2│        │ Key point 3│   ← MECE key line
   └─────┬──────┘        └─────┬──────┘        └─────┬──────┘
      support               support               support
```

- **Governing conclusion:** _____
- **Key line (MECE, same kind, logically ordered):**
  1. _____ → support: _____
  2. _____ → support: _____
  3. _____ → support: _____

## Ordering used within the key line
☐ Deductive ☐ Chronological ☐ Structural ☐ Comparative (by importance)

## Load + andragogy checks
- [ ] No group exceeds ~7±2 items.
- [ ] Each abstract point is anchored to a concrete consequence (Elephant).
- [ ] Detail that can be looked up is moved to a job aid, not spoken.
- [ ] For senior audiences: opens with *their* problem, honors their experience.
