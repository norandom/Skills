# Diagnostic Intake (Phase 0)

Fill this before compiling. If a field is unknown, mark it `?` and resolve it in
Phase 1.

## The three inputs

**raw_knowledge** — what are we transferring?
- Source asset(s): _____ (docs / repo / decision / tool / deck)
- Core conclusion in one sentence: _____

**cultural_assumptions** — where is it landing?
- Team / unit: _____
- Suspected basic underlying assumption: _____
- Recent relevant failure to learn from: _____

**network_topology** — through whom does it spread?
- Candidate eigenvector anchors ("whose opinion do people check?"): _____
- Natural dense cluster to seed first: _____
- Silos that must be bridged: _____

## The three one-liners (required)

1. **Target behavior** (an observable action, not "awareness"): _____
2. **One hidden assumption** I suspect governs this group: _____
3. **One high-leverage anchor** whose adoption pulls others: _____

## Gate

- [ ] Target behavior is an *action*, not a feeling/awareness.
- [ ] All three inputs are present (or flagged `?` with a plan to resolve).

If the target behavior is not yet an action, stop and fix that first.
